CASE 04 / CROSS-COMPANY SYNTHESIS

The shared service question.

Three brands present themselves as different organisations. Their records use different language, data formats and publication styles. Determine which relationships are evidenced, which are plausible but unproven, and what source would close the remaining gaps.

Part A - Network numbers

Can the three headline hospital network percentages be ranked? Reconstruct each denominator and state what it does not measure.

Part B - Service experience

Can the complaint and claims-speed metrics be compared? Document numerator, denominator, exclusions and channel.

Part C - Shared administration

Map every reference to shared administrative services. Which documents name the supplier, which only identify a code, and what does a register entry prove?

Part D - Confidence boundary

Write one supported conclusion, one partly supported conclusion, one disputed claim and one thing that must remain unknown.
