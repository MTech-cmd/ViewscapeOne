# Rivierzorg deployment: regional routing configuration

- **Record ID:** GG-CUST-118
- **Date:** 2026-05-03
- **Classification:** Internal source record

Regional queues are mapped to customer-defined service areas. A routing exception can be reassigned manually by authorised customer staff. The configuration export contains queue identifiers but omits the live staffing roster and partner capacity feed. “Route assigned” should not be read as “appointment available”.
