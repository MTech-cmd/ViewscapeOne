# Migration note: legacy identifiers and alias tables

- **Record ID:** GG-TECH-061
- **Date:** 2026-10-02
- **Classification:** Internal source record

The migration process preserves legacy ticket identifiers in an alias table. The alias table is not included in standard customer exports unless the archive option is selected. Some customers use local labels that do not map one-to-one to the current platform vocabulary.
