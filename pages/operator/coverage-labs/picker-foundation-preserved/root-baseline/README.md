# Dutch Health Insurance Picker 2027 - Coverage Lab Edition

> The `research-lab/` is a closed fictional training environment. All its insurers, parent groups, legal entities, policies, prices, institutions, banks, people, documents, events and findings are invented. Do not use the simulation as real insurance or legal information.

## Start the app

```bash
npm run serve
```

Open `http://localhost:8000`.

## Main areas

- `index.html` - Coverage Lab portal and side-by-side comparison.
- `research-lab/noordlicht/` - Y2K cyber-goth / Windows 7 Aero company world.
- `research-lab/rivierzorg/` - turquoise liquid-glass / XMB-inspired company world with optional dark mode.
- `research-lab/kompas/` - warm Windows 8 Metro / family tile company world.
- `research-lab/casebook/` - three distinct research trails and a cross-company exercise. No answers are shown on the public pages.
- `research-lab/institutions/` - simulated registers, filing service, oversight body, bank and newsroom.
- `FACILITATOR_ONLY/` - separate answer key and clue map; do not open before completing the casebook.
- `foundation/` - preserved original V0.1 foundation copy.

## Research output per company

Each company contains a full parent dossier, provider dossier, 2027 policy dossier, corporate timeline, claim register, source register, evidence desk, open questions, HTML research pages, wiki, website and ten fictional source PDFs.

## Validation

```bash
npm test
npm run validate
```

The base V0.1 JSON collections remain separate from the fictional company research lab. No scores or overall winner are added.
