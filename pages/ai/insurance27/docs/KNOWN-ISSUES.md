# Known Issues and Limitations

1. JSON schemas are provisional and require Res review, especially Claims and Sources vocabularies.
2. The runtime validator checks identifiers, relationships and assessment rating invariants; it does not yet execute every JSON Schema constraint.
3. Initial group/provider pairings are taken from the project scope and are not independently verified legal relationships.
4. No 2027 policies, premiums, benefits, provider contracts, wait times or reimbursement conditions are included.
5. No research claims or source records have been entered.
6. No CRUD editor, import/export workflow, database persistence, user questionnaire, scoring engine or recommendation engine exists yet.
7. The local development server is intended for local inspection only, not public deployment.
8. The `example.invalid` schema identifiers are placeholders, not hosted schema URLs.
